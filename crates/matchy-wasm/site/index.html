Local by design

The browser console matches evidence locally. It does not upload dropped files.

Built for messy evidence

Extract and match IPs, domains, hashes, exact strings, CIDRs, and glob patterns.

Path to real workflows

Try the console first, then move to the CLI, Rust API, or C API when you need automation.

CLI handoff

Use the same matching engine outside the browser.

matchy build threats.csv --output threats.mxy --input-format csv
matchy match threats.mxy auth.log --stats
