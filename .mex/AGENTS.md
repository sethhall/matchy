# matchy

## What This Is
A Rust workspace for building, validating, querying, and scanning memory-mapped IoC matching databases.

## Non-Negotiables
- Never edit `crates/matchy/include/matchy/matchy.h` directly; it is generated by cbindgen.
- Do not change `#[repr(C)]` binary format or C API signatures without explicit approval.
- Validate offsets and pointers before dereference; panics must not cross FFI.
- Public Rust APIs need `///` docs and focused tests.
- Run `cargo fmt` and clippy before commit.

## Commands
- Build: `cargo build`; release/C header: `cargo build --release -p matchy`
- Test: `cargo test --workspace`
- Lint: `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- Format: `cargo fmt --all`
- CI local: `make ci-local`
