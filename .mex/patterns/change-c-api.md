# Change C API

## Context
Main exported functions live in `crates/matchy/src/c_api/matchy.rs`. MaxMind compatibility lives in `crates/matchy/src/c_api/maxminddb_compat.rs` plus `mmdb_varargs.c`. `crates/matchy/include/matchy/matchy.h` is generated by `build.rs` and `cbindgen.toml`; do not edit it manually.

## Steps
1. Confirm whether the change affects a public C signature, `#[repr(C)]` struct, constant, or memory ownership rule; if yes, ask first.
2. Add or change Rust exported symbols with `#[no_mangle] pub unsafe extern "C" fn ...`.
3. Validate every pointer before dereference, including output pointers and null-terminated strings.
4. Return existing `MATCHY_ERROR_*` codes or add documented codes consistently.
5. Keep ownership explicit: add/free pairs for new allocations, and document whether C or Rust owns each pointer.
6. Add generated-header support through Rust declarations and `cbindgen.toml`; never patch `matchy.h` directly.
7. Add C coverage in `crates/matchy/tests/test_c_api.c`, `test_c_api_extensions.c`, or `test_mmdb_compat.c` as appropriate.

## Gotchas
- Current C API docs promise panic containment, but exported functions do not use `catch_unwind`; add panic guards for new fallible boundaries instead of expanding the gap.
- `matchy_builder_build` uses `libc::malloc` specifically so C callers can `free()` the buffer.
- `matchy_result_t` stores `_data_offset` and `_db_ref`; it is only meaningful while the database handle is alive.
- `cbindgen.toml` excludes `MMDB_*` symbols from `matchy.h`; MaxMind symbols belong to `maxminddb.h`.
- `build.rs` post-processes generated `sockaddr` declarations.

## Verify
- `cargo build --release -p matchy`
- `make test-c`
- `make test-c-ext`
- `make test-mmdb`
- `cargo test -p matchy`
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`

## Debug
- If the header is wrong, inspect Rust exports and `cbindgen.toml` before touching generated files.
- If C tests cannot link, confirm `target/release/libmatchy.a` exists from the release build.
- If nested data reads fail, check `matchy_aget_value`, `matchy_result_get_entry`, and data offset lifetime.
