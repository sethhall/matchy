# Stack

## Core Technologies
- **Rust 2021, rust-version 1.87** - workspace-wide language/runtime baseline.
- **Cargo workspace v2.0.1** - default member is `crates/matchy`; internal crates use path dependencies at version `2.0.0`.
- **CLI binary `matchy`** - gated by default `cli` feature and implemented with `clap` derive.
- **Native C ABI** - `matchy` builds `rlib`, `staticlib`, and `cdylib`; generated by `build.rs` and `cbindgen`.
- **WASM/WASI targets** - `matchy-wasm` builds for `wasm32-unknown-unknown`; `matchy` checks `wasm32-wasip1` without default features.

## Key Libraries
- **`zerocopy`** - used for C-compatible binary structs; preserve layout and size assertions.
- **`memmap2`** - native database loading uses read-only mmap; WASM owns bytes instead.
- **`rayon` + `crossbeam-channel`** - build literal hash shards and run bounded reader/worker pipelines.
- **`lru` + `rustc-hash`** - per-thread query caches use `FxHasher`; cache keys are database generation IDs.
- **`xxhash-rust`** - literal strings use 96-bit XXH3-derived hashes in `matchy-literal-hash`.
- **`serde`/`serde_json` + `csv` + `chrono`** - input parsing and `DataValue` JSON/timestamp conversion.
- **`flate2`** - gzip input support through the file reader layer.
- **`cbindgen`** - build dependency that generates `crates/matchy/include/matchy/matchy.h`; do not hand-maintain headers.

## What We Deliberately Do NOT Use
- No pointer fields in serialized data - mmap requires stable byte offsets.
- No hand-edited C headers - change Rust API or `cbindgen.toml`, then rebuild.
- No hand-rolled CLI parsing - commands and flags use `clap` derive in `crates/matchy/src/bin/matchy.rs`.
- No unbounded producer queues in parallel processing - `process_files_parallel` uses bounded `crossbeam_channel` queues to cap memory.
- No new dependencies without approval - workspace already carries focused crates for hashing, mmap, parsing, concurrency, and FFI.

## Version Constraints
- Rust `1.87` is the declared minimum.
- Current Paraglob binary format is v5 with a 112-byte `ParaglobHeader`.
- Current literal hash format is v3 (`LHSH`, 32-byte header).
- Release builds of `matchy` run `build.rs`, which uses `cbindgen 0.29`.
